# DailyRewards Plugin Configuration

**Configured by: Nasser (NasDev12)**

Date Created: March 7, 2026

## Overview
This is a professional, production-ready DailyRewards plugin configuration for Minecraft servers.

## Features
- ✅ 3-Tier Reward System (Day 1, 7, 30)
- ✅ Streak Bonus System
- ✅ Economy Integration (Vault)
- ✅ PlaceholderAPI Support
- ✅ Custom Messages & Notifications
- ✅ Admin Commands
- ✅ SQLite Database

## Configuration Files
- `config.yml` - Main configuration
- `messages.yml` - Customizable messages
- `spigot.yml` - Server settings

## Setup Instructions
1. Place config files in `/plugins/DailyRewards/`
2. Restart server
3. Use `/daily claim` to test
